# Craftorio

**Craftorio** is an automation and survival game built with **Java** and **LibGDX**.

Spawn into a procedurally generated world with a basic starter-pack of resources. Extract raw materials, automate your production lines, and establish a robust defense system to protect your base from inevitable enemy attacks.

---

### Core Mechanics
*   **Automation:** Build mining drills, furnaces, and crafting machines to create complex production chains.
*   **Logistics:** Implement conveyor belts to transport resources across your factory.
*   **Defense:** Deploy automated turrets and craft ammunition to fend off enemies spawning from procedural lairs.
*   **Exploration:** Navigate a procedural grid-based world to locate vital ore deposits and strategically plan your base expansion.

### Tech Stack
*   **Language:** Java
*   **Framework:** LibGDX
*   **World Gen:** Procedural Grid Generation
